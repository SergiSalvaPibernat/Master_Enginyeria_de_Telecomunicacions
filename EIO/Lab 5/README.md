# Lab 5 - Band-Pass Filter Analysis

This project corresponds to the fifth laboratory in the EIO course and centers on the design and analysis of a band-pass filter.

## Objective

The aim of the laboratory is to study how a band-pass filter behaves in an electronic circuit, with emphasis on frequency selectivity and signal filtering.

## Main files

- `EIO Lab 5 Bandpassfilter.docx` – main report/documentation for the lab

## Topics covered

This lab addresses:

- filter theory and frequency response
- band-pass behavior
- passband and stopband interpretation
- practical characterization of filter performance

## Learning outcomes

By completing this lab, students gain experience in:

- understanding filter operation in the frequency domain
- relating circuit design to measured response
- interpreting filter performance from experimental data
- producing a clear technical description of the results

## Notes

This laboratory builds on the earlier instrumentation topics by applying measurement and analysis techniques to a key signal-processing component: the band-pass filter.
