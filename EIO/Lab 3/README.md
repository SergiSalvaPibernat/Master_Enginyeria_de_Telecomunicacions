# Lab 3 - Instrument Control and Measurement Systems

This project is the third laboratory in the EIO course and focuses on using measurement instruments in a coordinated setup to acquire and analyze electronic signals.

## Objective

The lab aims to strengthen the student’s understanding of automated measurement workflows, instrument communication, and signal analysis through practical laboratory software.

## Main files

- `func_gen_2021_ALL.vi` – function generator control interface
- `meas_mult_2021.vi` – multimeter acquisition interface
- `meas_osc_2021.vi` and `meas_osc_RS_2021.vi` – oscilloscope measurement routines
- `LAB3_Instrument_driver_tutorial.pdf` – tutorial for the instrument interface
- `EIO LAB3 - Prework.docx` – preparatory material
- `EIO LAB3.docx` – final lab report

## Topics covered

The laboratory addresses:

- instrument driver usage
- communication between software and measurement equipment
- oscilloscope-based signal observation
- multimeter and function generator configuration
- validation of measured signal properties

## Learning outcomes

By the end of this lab, students should be able to:

- operate multiple measurement instruments from a common interface
- configure source and measurement devices correctly
- capture and interpret data from different instrument types
- document the measurement process and the obtained results

## Notes

This lab builds on the previous practical work by combining multiple test and measurement tools in a more integrated instrumentation workflow.
