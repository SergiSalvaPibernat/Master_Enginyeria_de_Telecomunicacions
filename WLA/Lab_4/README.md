# Lab 4 - Advanced Antenna Simulation and Analysis

This project is the final antenna-related laboratory in the WLA coursework. It contains an advanced CST simulation setup and accompanying report files for the study of an antenna or electromagnetic structure.

## Objective

The purpose of the laboratory is to explore more advanced antenna behavior and characterize the structure through simulation. The project emphasizes:

- design validation
- frequency-domain analysis
- far-field radiation characteristics
- parameter optimization and interpretation

## Main files

- `Pràctica4.cst` – main CST project file
- `Pràctica4/` – simulation model and result folders
- `Lab4newpaper.pdf` – project documentation or draft paper
- `Laboratory 4 Report.pdf` – formal report for the laboratory
- generated results in `Result/` such as far-field and field-solver outputs

## Topics covered

The project includes advanced analysis of:

- antenna response under different conditions
- field distribution and power flow
- far-field pattern evaluation
- performance checking against design specifications
- interpretation of simulation data for final conclusions

## Methodology

The lab uses a high-frequency electromagnetic solver to model the structure and extract key performance indicators. Results are analyzed from both a physical and engineering perspective, allowing evaluation of how the design behaves across the relevant frequency range.

## Learning outcomes

This laboratory develops competence in:

- advanced antenna simulation workflows
- interpreting complex electromagnetic results
- evaluating design quality from far-field and matching behavior
- preparing technical conclusions based on simulation data

## Notes

This lab represents the most advanced part of the WLA sequence, combining design, simulation, and technical reporting to assess the performance of an antenna system in a realistic engineering context.
