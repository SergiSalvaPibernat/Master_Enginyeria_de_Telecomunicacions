# Lab 2 - Mutual Impedance and Current Distribution of Dipoles

This project studies the electromagnetic behavior of wire antennas using MATLAB. The work is centered on the `Laboratory_2.m` script and related functions, especially the mutual impedance and current-distribution calculations for dipoles.

## Objective

The purpose of the lab is to analyze how dipole antennas interact electromagnetically and how the current distribution changes depending on their length and geometry.

## Main files

- `Laboratory_2.m` – main script with the exercises
- `MATLAB FUNCTIONS-20210926/` – supporting functions such as `z12_dip.m` and `current_distribution`
- `Enunciat Lab 2.pdf` – statement of the laboratory assignment
- `Laboratory 2 Report WLA.pdf` – report version of the work

## Topics covered

The project includes exercises on:

- real and imaginary parts of mutual impedance between two dipole segments
- current distribution along finite-length dipoles
- comparison between MoM-based and transmission-line models
- input impedance estimation
- directivity comparisons for different dipole lengths

## Methodology

The lab uses a method-of-moments (MoM) approach to approximate current distribution, and compares it with a transmission-line approximation. This allows students to evaluate how the antenna behaves at different electrical lengths, such as:

- 0.1 λ
- 0.25 λ
- 0.5 λ
- 5/8 λ

The results are visualized through current-distribution plots and radiation-pattern comparisons.

## Learning outcomes

This laboratory helps students understand:

- mutual coupling between antenna elements
- current distribution along the dipole
- impedance behavior as a function of geometry
- the difference between numerical and simplified antenna models

## Notes

This is a key electromagnetic antennas exercise, connecting theoretical antenna theory with numerical simulation and practical interpretation of the results.
