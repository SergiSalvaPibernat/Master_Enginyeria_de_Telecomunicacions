# Lab 3 - Antenna Design and Simulation in CST

This laboratory focuses on the modeling and analysis of an antenna using CST Studio Suite. The project contains several CST simulation files and generated result plots that describe the antenna’s electromagnetic behavior.

## Objective

The main objective is to design and study an antenna structure and analyze its performance in terms of:

- reflection coefficient / S-parameter response
- input matching
- radiation behavior
- impedance and Smith-chart results
- near- and far-field characteristics

## Main files

- `LAB3.cst` and `s1.cst` – CST design files
- `S1/` – simulation setup and results directory
- `LAB3/` – additional project data and model files
- `Exercici1-2 -e-field.png` and related images – field plots
- `exercici 2- impedance.png`, `exercici 2- 50ohms.png`, `Exercici1-2-smith-chart.png` – matching and impedance visualization
- `Laboratory 3 Report.pdf` and `lab3new.pdf` – lab documentation

## Topics covered

The project includes analysis of:

- antenna resonance and matching conditions
- S-parameter variation with frequency
- frequency-dependent impedance behavior
- Smith chart interpretation
- electric-field distribution around the antenna
- practical antenna design evaluation

## Methodology

The design is evaluated in a simulation environment by examining how the antenna responds to excitation across a frequency range. Results such as field maps and impedance plots are used to determine whether the structure is properly matched and how efficiently it radiates.

## Learning outcomes

This lab develops skills in:

- antenna design with electromagnetic simulation software
- interpreting RF matching data
- understanding the relation between geometry and electrical behavior
- evaluating performance using visualization tools and plots

## Notes

This project bridges theory and application by introducing a realistic antenna design workflow, using simulation results to assess whether the structure meets the expected operating conditions.
