# Assignment 4 - Virtualization of Network Resources

This assignment explores the concept of network resource virtualization and how network functions can be abstracted and managed more flexibly.

## Objective

The purpose of the assignment is to understand networking virtualization techniques and their application in modern communication systems, including how virtualized resources are modeled and utilized.

## Main files

- `CN-Assignment4.Virtualization of Network Resources.docx` – assignment guidance and documentation
- `CN_assignment4.py` – Python implementation or supporting script
- `Assignment.py` – additional code relevant to the assignment

## Topics covered

The assignment focuses on:

- resource virtualization in networks
- abstraction of network capabilities
- virtualized infrastructure modeling
- practical implementation using scripting/code

## Learning outcomes

Students learn to:

- understand the principles of network virtualization
- interpret how abstract network resources are managed
- connect theory to a practical implementation approach
- analyze the role of virtualization in modern networking environments

## Notes

This final assignment introduces a more advanced networking concept and complements the earlier work on wireless networking, IPv6, and routing by focusing on how resources can be virtualized and optimized in modern network architectures.
