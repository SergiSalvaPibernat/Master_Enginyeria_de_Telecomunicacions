# Assignment 1 - WLAN Fundamentals

This assignment focuses on wireless local area networks (WLANs) and the fundamentals of IEEE 802.11 technologies.

## Objective

The goal of this project is to study the behavior and characteristics of WLAN systems, with emphasis on wireless communication principles, network operation, and protocol analysis.

## Main files

- `CN-Assignment1_WLAN.docx` – assignment statement and theoretical guidance
- `802.11Traces.pcapng` – packet capture file used for analysis of WLAN traffic

## Topics covered

This assignment typically includes:

- IEEE 802.11 concepts
- wireless network behavior and architecture
- packet-level analysis of WLAN traffic
- interpretation of captured traces
- practical understanding of wireless communication in computer networks

## Learning outcomes

Students develop skills in:

- understanding WLAN operation
- reading and analyzing network captures
- identifying wireless communication patterns
- relating protocol behavior to network performance

## Notes

This first assignment introduces core concepts of wireless networking and acts as a foundation for more advanced network-routing and virtualization topics in later assignments.
