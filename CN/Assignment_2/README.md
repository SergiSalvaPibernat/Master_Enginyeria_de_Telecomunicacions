# Assignment 2 - IPv6 and 6LoWPAN

This assignment focuses on IPv6 networking and the 6LoWPAN adaptation layer used in constrained wireless networks.

## Objective

The purpose of this project is to understand how IPv6 is used in modern network environments, as well as how low-power wireless personal area networks adapt IPv6 packets for constrained devices.

## Main files

- `CN-Assignment2_IPv6.docx` – assignment document for IPv6 concepts
- `6LoWPAN.pdf` – supporting material about 6LoWPAN
- `RTLS_introduction.pdf` – background information related to localization and wireless networking concepts

## Topics covered

The assignment addresses:

- IPv6 addressing and protocol structure
- routing and addressing considerations in IP networks
- adaptation of IPv6 over low-power networks
- 6LoWPAN architecture and operation
- integration of IPv6 in constrained environments

## Learning outcomes

Students gain experience in:

- understanding IPv6 protocol operation
- analyzing network communication in constrained environments
- learning how adaptation layers enable IPv6 in low-power wireless systems
- relating theory to real networking scenarios

## Notes

This assignment introduces key ideas for advanced networking topics, especially in the context of IoT, low-power devices, and next-generation wireless communication.
