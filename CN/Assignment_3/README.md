# Assignment 3 - Routing Protocols and Network Traces

This assignment focuses on routing in IP-based networks, with practical analysis of packet captures related to routing protocols.

## Objective

The goal is to understand how routing protocols operate in real networks and to analyze routing behavior through captured traffic data.

## Main files

- `CN-Assignment3_Routing.docx` – assignment document for the routing exercise
- `CN4-Traces1-RIP1.pcap` – trace for RIP routing behavior
- `CN4-Traces2-RIP2.pcap` – second routing trace for comparison
- `CN4-Traces3-BGP.pcap` – BGP-related packet capture

## Topics covered

The project includes analysis of:

- RIP routing
- BGP operation
- routing information exchange
- network packet inspection
- comparison between different routing protocols

## Learning outcomes

Students develop skills in:

- interpreting routing traffic
- understanding protocol operation from packet traces
- comparing behavior of different routing protocols
- analyzing routing decisions in network communication

## Notes

This assignment provides practical exposure to network routing by combining protocol theory with packet-level evidence from real traces.
