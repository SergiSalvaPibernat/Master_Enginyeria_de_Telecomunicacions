# WhatsApp Exercise Android App

This project is the Android mobile application component of the WhatsApp-style exercise.

## Objective

The goal is to build a messaging application for Android, targeting a user-facing chat experience and interaction with a backend service.

## Main contents

The folder contains the Android Studio project, Gradle configuration, app sources, and generated build artifacts.

## Learning outcomes

- Create an Android application UI
- Integrate mobile app logic with backend services
- Understand message-based interaction in mobile applications
- Practice Android app development and project structure

## Notes

This project completes the mobile application side of the WhatsApp exercise and is closely related to the server-side database project in the same submission set.
