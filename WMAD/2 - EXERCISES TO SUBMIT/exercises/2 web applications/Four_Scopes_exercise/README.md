# Four Scopes Exercise

This project explores the concept of scopes in web application development and how different application layers or contexts interact.

## Objective

The exercise focuses on understanding how data and logic are organized across different scopes or layers within a web application.

## Main contents

The folder contains the project files for a small Java web application that demonstrates scope-related behavior.

## Learning outcomes

- Understand web application context and scope
- Learn how variables and objects are managed across application layers
- Practice Java EE / web application organization

## Notes

This project is intended to reinforce core web programming ideas and application design patterns used in larger systems.
