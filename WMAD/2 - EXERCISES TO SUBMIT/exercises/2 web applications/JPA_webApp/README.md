# JPA Web Application

This project demonstrates the use of Java Persistence API (JPA) in a web application context.

## Objective

The exercise focuses on object-relational mapping and persistence using JPA instead of direct SQL management, allowing Java entities to be stored and retrieved from a database more naturally.

## Main contents

The folder contains application files and SQL scripts used to configure and run a JPA-based web project.

## Learning outcomes

- Work with JPA entities and persistence units
- Manage database records through Java objects
- Understand ORM concepts in a web environment
- Compare direct JDBC access with JPA-based persistence

## Notes

This project introduces a more modern and scalable approach to database interaction for web applications.
