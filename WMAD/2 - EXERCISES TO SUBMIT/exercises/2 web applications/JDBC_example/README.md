# JDBC Example

This project is a database access exercise using Java Database Connectivity (JDBC).

## Objective

The goal of the project is to practice connecting a Java application to a relational database and performing CRUD-style operations through SQL queries.

## Main contents

The folder includes Java classes and database scripts to demonstrate basic JDBC usage.

## Learning outcomes

- Connect Java applications to a database
- Execute SQL statements from Java
- Understand database access patterns in web applications
- Practice data persistence basics

## Notes

This exercise is a practical introduction to data management in Java-based applications and is a key building block for web applications with persistent storage.
