# eCommerce Exercise

This project is a web application exercise focused on an e-commerce scenario.

## Objective

The objective is to build a small e-commerce prototype with typical features such as product display, shopping cart logic, and database-backed product information.

## Main contents

The project includes Java web application files, static resources, and SQL scripts representing an online store.

## Learning outcomes

- Implement a simple e-commerce application
- Manage products, users, and cart logic in a web environment
- Use a database to store application data
- Practice full-stack web development basics

## Notes

This is one of the most complete web exercises in the submission set and demonstrates the integration of front-end, backend logic, and persistence.
