# JDBC Web Application

This project extends the JDBC example into a web application that interacts with a database.

## Objective

The goal is to build a small Java web app that communicates with a database and presents dynamic content through web pages.

## Main contents

The project contains Java web application files, database scripts, and configuration resources needed to run the app.

## Learning outcomes

- Build a web app with database access
- Use JDBC in a servlet/JSP environment
- Handle persistence and user interaction in a web context
- Understand the relationship between UI, logic, and database layers

## Notes

This project is an intermediate step between simple database access and complete full-stack web applications.
