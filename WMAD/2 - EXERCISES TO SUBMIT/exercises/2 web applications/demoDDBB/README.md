# Demo Database Project

This project is a demo application focused on database integration and data management in a web environment.

## Objective

The goal of this exercise is to practice building a small application backed by a database and to understand how data flows between the application, persistence layer, and UI.

## Main contents

The project contains Java web application files and SQL scripts for creating and populating a sample database.

## Learning outcomes

- Create and populate a database schema
- Connect application logic with persistent data
- Design simple data-driven web functionality
- Learn the fundamentals of backend integration

## Notes

This project acts as a practical example of how simple web applications integrate databases into user-facing functionality.
