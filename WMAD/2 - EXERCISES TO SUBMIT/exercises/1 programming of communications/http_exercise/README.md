# HTTP Exercise

This project is a basic programming exercise focused on web communication and HTTP requests.

## Objective

The goal of this exercise is to practice client-server interaction through HTTP, handling request/response communication and understanding how a simple web-based application exchanges data.

## Main contents

The project contains Java web components and related configuration files for a simple HTTP-based application.

## Learning outcomes

- Understand HTTP communication basics
- Implement request handling in a web application
- Work with Java-based server-side logic
- Learn how web interactions are built and tested

## Notes

This is a foundational exercise in web programming and network communication, preparing students for more complex web and messaging applications.
