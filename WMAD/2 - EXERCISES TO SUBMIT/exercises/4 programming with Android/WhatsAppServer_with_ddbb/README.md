# WhatsApp Server with Database

This project is a server-side component for an Android messaging application, backed by a database.

## Objective

The project aims to provide the backend logic for a WhatsApp-like application, including user management, messaging storage, and data persistence.

## Main contents

The folder contains Java server-side application files and SQL scripts necessary for database-driven messaging.

## Learning outcomes

- Implement a backend service for a mobile messaging app
- Manage user data and messages in a database
- Understand client-server communication in mobile systems
- Practice integration between Android and server-side logic

## Notes

This project connects the mobile app development exercise with server-side persistence and represents a practical full-stack messaging architecture.
