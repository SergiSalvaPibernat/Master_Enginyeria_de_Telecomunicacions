# Instant Messaging Remote with Database

This project combines remote instant messaging with persistent storage in a database.

## Objective

The goal is to build a messaging application that supports remote communication while storing user and message data in a database for persistence.

## Main contents

The folder contains the client and server project files, along with SQL schemas and supporting resources for database-backed messaging.

## Learning outcomes

- Build distributed messaging applications
- Store application data persistently in a database
- Integrate networking with persistence
- Understand the architecture of full messaging systems

## Notes

This project is one of the most complete exercises in the set, bringing together interactive applications, networking, and database management.
