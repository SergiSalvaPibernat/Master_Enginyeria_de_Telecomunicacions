# Upper Case Exercise

This project focuses on simple client/server interaction where text is converted to uppercase.

## Objective

The goal is to demonstrate basic communication between a client and a server by sending text and receiving it transformed into uppercase.

## Main contents

The folder contains the project files for a small socket-based application, including client and server logic.

## Learning outcomes

- Understand simple client-server communication
- Practice text processing in a networked application
- Learn how data is transmitted and transformed in real time

## Notes

This exercise is a small but important example of interactive programming with a clear, easy-to-follow communication flow.
