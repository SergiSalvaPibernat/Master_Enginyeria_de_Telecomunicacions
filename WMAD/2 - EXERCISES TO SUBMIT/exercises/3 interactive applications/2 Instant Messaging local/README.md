# Instant Messaging Local

This project implements a local instant messaging application where clients communicate within the same local environment.

## Objective

The exercise focuses on real-time communication between multiple users or local clients and the handling of message exchange in a networked application.

## Main contents

The folder contains the project files for a local messaging system, including client/server interaction and message flow logic.

## Learning outcomes

- Implement local client-server communication
- Manage message exchange between users
- Learn the basis of interactive real-time applications
- Practice network programming concepts

## Notes

This project is a foundational step toward distributed messaging systems and demonstrates the core architecture of instant messaging.
