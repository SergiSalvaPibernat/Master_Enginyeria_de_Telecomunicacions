# Instant Messaging Remote

This project extends the instant messaging concept to a remote client-server communication model.

## Objective

The goal is to implement a basic messaging application where clients communicate over a network, not just within a local environment.

## Main contents

The project contains the client and server code for remote messaging, along with configuration and support files.

## Learning outcomes

- Build remote network communication for messaging
- Manage client/server interaction across a distributed system
- Understand real-time message exchange in a remote setting

## Notes

This project represents a step forward from local messaging by introducing remote connectivity and network-based communication.
