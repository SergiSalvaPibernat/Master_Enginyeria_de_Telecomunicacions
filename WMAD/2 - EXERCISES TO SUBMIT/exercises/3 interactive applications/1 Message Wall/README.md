# Message Wall

This project is an interactive web application inspired by social message walls, where users can publish and view messages.

## Objective

The exercise focuses on creating a simple interactive application where messages are displayed to users in a shared wall-like interface.

## Main contents

The folder contains the application project files for a message wall, including front-end and server-side logic.

## Learning outcomes

- Build interactive page behavior
- Handle user-generated content
- Understand client-server communication for dynamic applications
- Practice simple application state management

## Notes

This project is a practical example of an interactive web app that emphasizes user communication and dynamic content display.
